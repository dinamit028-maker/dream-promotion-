## 6. אבטחה, ב-Supabase האמיתי (RLS)

מאז 2.41 ההרשאות הן לפי **עסק**, לא לפי משתמש. הבדיקה: האם משתמש של עסק אחד רואה שורות של **עסק אחר**.
ב-SQL Editor, עם ה-uuid של בעלים של עסק A (מ-Authentication ← Users). הבדיקה רצה בתוך טרנזקציה שמתבטלת, כך שלא משתנה כלום:
```sql
begin;
set local role authenticated;
select set_config('request.jwt.claims', json_build_object('sub', '<UUID של A>', 'role', 'authenticated')::text, true);
select set_config('request.jwt.claim.sub', '<UUID של A>', true);
select 'מסמכים של עסק אחר' as t, count(*) from public.documents where business_id <> public.current_business_id()
union all select 'מכירות של עסק אחר', count(*) from public.sales where business_id <> public.current_business_id()
union all select 'לקוחות של עסק אחר', count(*) from public.leads where business_id <> public.current_business_id()
union all select 'תשלומים של עסק אחר', count(*) from public.payments where business_id <> public.current_business_id()
union all select 'מדיה של עסק אחר', count(*) from public.media where business_id <> public.current_business_id();
rollback;
```
**אמור לחזור:** 0 בכל השורות. בדיקות התקיפה המלאות (עסק מול עסק, קופאי/ת, צופה, מנהל-על) רצות אוטומטית על Postgres 16 מקומי: `tests/sql/*.check.sql` (סעיף 19).

**לפני הבדיקה בטלפון:**
1. **מיגרציה 4200 על המסד החי — רק אחרי אישור**, בלי הערת ה-rollback שבסוף הקובץ. לפני ההחלה, בקריאה בלבד:
```sql
select to_regclass('public.client_sessions') as sessions, to_regclass('public.client_packages') as packages;
```
   - **אמור לחזור:** `client_sessions` ו-`null` (4100 קיימת, 4200 עוד לא).
2. **אחרי ההחלה,** בקריאה בלבד:
```sql
select c.relname, c.relrowsecurity,
  (select count(*) from pg_policies p where p.schemaname = 'public' and p.tablename = c.relname and p.permissive = 'RESTRICTIVE') as restrictive,
  (select count(*) from pg_policies p where p.schemaname = 'public' and p.tablename = c.relname and p.permissive = 'PERMISSIVE') as permissive,
  (select count(*) from pg_trigger t where t.tgrelid = c.oid and not t.tgisinternal) as triggers
from pg_class c where c.relnamespace = 'public'::regnamespace and c.relname in ('client_packages', 'client_package_uses') order by 1;
select p.proname, p.prosecdef, array_to_string(p.proacl, ' ') as acl from pg_proc p
where p.pronamespace = 'public'::regnamespace
  and p.proname in ('client_session_add', 'client_packages_check', 'client_package_uses_check', 'documents_package_link', 'client_sessions_cancelled') order by 1;
select reloptions from pg_class where oid = 'public.client_package_status'::regclass;
select count(*) from information_schema.columns where table_schema = 'public'
  and ((table_name = 'catalog_items' and column_name like 'package\_%') or (table_name = 'client_sessions' and column_name in ('cancelled_at', 'cancelled_by', 'cancel_reason')));
```
   - **אמור לחזור** (כמו במסד המקומי):
     - בשתי הטבלאות: RLS פעיל, 6 RESTRICTIVE, 3 רגילות, 5 טריגרים.
     - פונקציות הטריגרים: security definer, ורק `postgres` ו-`service_role` יכולים להריץ.
     - `client_session_add`: לא security definer, ו-`authenticated` יכול לקרוא לה.
     - `{security_invoker=true}`, ו-6 עמודות.
3. **לבדוק בעסק בדיקה** — המסמכים שמופקים כאן אמיתיים: מספור רציף, לא נמחקים, ותיקון רק בזיכוי.

**בטלפון:**
1. **כספים → הכנסות → "חבילות":** "עוד לא נמכרו חבילות". **"+ חבילה חדשה"** — עורך המוצר, עם "תנאי החבילה": 6 טיפולים, סוג "לייזר", 6 חודשים → שמירה.
   - **אמור לקרות:** החבילה ב"החבילות בקטלוג", עם "6 טיפולים · לייזר · 6 חודשים".
2. **כרטיס של לקוח בדיקה → כספים → "📦 מכירת חבילה":** לבחור את החבילה → "חשבונית — תשלום אחר כך" → "מכירה והפקת המסמך" → אישור.
   - **אמור לקרות:** בכרטיס "📦 חבילות" — "נותרו 6 מתוך 6 · בתוקף עד …". במסמכים — חשבונית מס על המחיר.
3. **"חבילות" → החבילה → "פתיחת המסמך" → "קבלה על תשלום"** — פעמיים, חצי מהסכום בכל פעם.
   - **אמור לקרות:** "שולם … מתוך …" מלא. הלקוח/ה לא ב"חייבים".
4. **בכרטיס → "🩺 טיפולים שבוצעו" → "+ רישום טיפול שבוצע":** "לנכות מהחבילה" כבר מסומן → "רישום וניכוי מהחבילה". פעמיים.
   - **אמור לקרות:** "נותרו 4 מתוך 6". בטיפול: "נוכה מ"6 טיפולי לייזר"".
5. **"ביטול הטיפול"** על אחד הטיפולים, עם סיבה.
   - **אמור לקרות:** "נותרו 5 מתוך 6", והטיפול מסומן "בוטל: …".
6. **"חבילות" → החבילה → "ביטול החבילה":** המערכת מציעה זיכוי על מה שלא נוצל, והחזר. לבדוק את הסכומים → סיבה → "הפקת זיכוי וביטול החבילה".
   - **אמור לקרות:** חשבונית זיכוי במסמכים, ההחזר ביומן התשלומים, והחבילה "בוטלה". "שולם מראש ועוד לא נוצל" בדוח — 0.
7. **כקופאי/ת:** אין "כספים", ובכרטיס אין חבילות.
